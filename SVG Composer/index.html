How to use these controls — beginner steps

For text you create in Badge Composer: add a Text layer, type your label, choose its font and size, select that text layer, then click the main Auto center button above the artboard. No export, import, metadata, or manual writing-line step is needed.

For converted-to-path text: use the same workflow. Badge Composer keeps the original text, font data and size in the layer model even when its preview is drawn as vector paths. Auto Center uses those retained values.

For several selected text layers: select the labels and click Auto center. They are centered together as one horizontal group and their alphabetic baselines are automatically aligned. The text size and layer scale are preserved.

How it detects the writing line: for an editable text layer, the browser measures the actual font. If you embedded a font, the editor uses its saved font outline metrics. This recognizes descenders such as y, g, p, q and j without asking you to mark the line.

Imported SVGs and old paths: Auto Center still works immediately using visible artwork bounds. If an imported file contains real SVG text, the editor can measure its font metrics. A completely flattened third-party path may not contain enough information to recover the exact original writing line; in that case the editor safely uses visible-shape centering rather than guessing.

Advanced controls: the horizontal and vertical reference menus are optional overrides. Leave them at their defaults unless you have a specific layout requirement. The normal Auto Center button makes the automatic choice for Badge Composer text.

Important: Auto Center moves artwork but never changes its font size or layer scale. Use Fit artwork only when you intentionally want to enlarge or shrink artwork to fit the padding.

You can create and center labels entirely inside Badge Composer. Text-to-SVG is optional, not required for automatic centering.
