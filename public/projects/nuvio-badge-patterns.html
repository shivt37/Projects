Select the badges you want; patterns are rebuilt from only your selection, so removing a tier never leaves the others switched off.

  • Nuvio does not enforce first-match-wins; the regexes exclude each other. Keep audio in one group and AI in its own group.

  • Mobile copy: mobile browsers often block automatic copy from a file:// page. Best fix: open this file from an HTTPS URL (e.g. GitHub Pages). Otherwise the page falls back to legacy copy, then to a manual box — long-press the text → Select All → Copy.
