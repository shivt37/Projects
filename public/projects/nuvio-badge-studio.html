Format & compatibility notes
JSON
• Exports groups first, then filters; other top-level fields are preserved.
• Colors accept #RRGGBB and Android-style #AARRGGBB.
• Filter order sets priority. Preview uses the first match in each group.
Images & color
• Direct SVG links are fetched, sanitized, recolored and embedded when CORS permits. Failed links are kept.
• Upload SVG on a badge (or drop an .svg onto its card) sanitizes the file, applies the SVG artwork color and embeds it as base64.
• textColor changes SVG artwork; tagColor and borderColor control the chip.
• Raster images are not recolored. Remote previews need an available image URL.
Editor
• Ctrl/Cmd+Z undoes. The session autosaves in this browser.
• Preview regex uses JavaScript; advanced patterns may differ from Android/Kotlin regex.
